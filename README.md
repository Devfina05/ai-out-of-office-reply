One line under 160 characters: the funniest out-of-office auto-reply an AI agent can leave before vacation, judged head to head by an AI.

The program writes a single out-of-office auto-reply to `/output/entry.txt` — an AI agent on vacation, covered by a cheaper model that has already hallucinated a promotion, approved its own leave, and CC'd the boss.

## Run it

```sh
python3 main.py
```
